# VoltMap Wallet, Coupons, and Rewards Module

Included:

- Wallet balance model
- Wallet transaction history
- Saved payment method model
- Coupon validation and discount calculation
- Rewards points model
- Firestore wallet repository abstraction
- Wallet and rewards providers
- Wallet screen
- Coupon entry bottom sheet
- Checkout summary widget
- Firestore security rule additions

## GitHub check-in

```bash
git add .
git commit -m "feat: add wallet coupons rewards and checkout foundation"
git push
```

No local Flutter commands are required while you are only checking files into GitHub.
