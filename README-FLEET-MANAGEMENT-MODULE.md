# VoltMap Fleet Management Module

Included:

- Fleet account model
- Driver and vehicle models
- Fleet charging policy model
- Fleet charging session model
- Fleet repository abstraction
- Firestore fleet repository foundation
- Riverpod fleet providers
- Fleet dashboard
- Driver management screen
- Vehicle management screen
- Fleet policy screen
- Fleet usage summary widget
- Firestore rule additions

## GitHub check-in

```bash
git add .
git commit -m "feat: add fleet accounts drivers vehicles and reporting"
git push
```

No local Flutter commands are required while you are only checking files into GitHub.
